The figure shows numerical output from the Model v0 persistence equation for 
<br> selected values of $\beta$, using the initial condition $S(0)=1$.

Higher values of $\beta$ retain a larger fraction of the existing propagation state 
<br>  between discrete time steps, while $\beta=1$ preserves it unchanged.

The figure is intended as a simple numerical illustration of the persistence term.
